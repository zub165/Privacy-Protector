How to delete data (inside the app)

  • Settings → Erase app files: removes files created by Privacy Protector (documents/cache/temp) and demo data.
  • Controls → Emergency clear: fast reset of in-app logs, caches, and most preferences.
  • Controls → Duplicate contacts/photos: finds duplicates and deletes them after confirmation.

How to clear other apps (system steps)

Operating systems protect apps from deleting each other’s private data. Privacy Protector can open system screens, but you confirm actions.

  • Android: Settings → Apps → (Select app) → Storage & cache → Clear cache / Clear storage.
  • iOS: Settings → General → iPhone Storage → (Select app) → Offload App / Delete App.

Django backend (optional)

You can configure a base URL like https://api.yoursite.com:8001 in the app Settings. The backend can accept event logs (audit/analytics), but it cannot delete data on the device.

  • GET /api/v1/health/ → returns {"status":"ok"}
  • POST /api/v1/privacy-events/ → accepts event JSON, optional Authorization: Bearer ...
